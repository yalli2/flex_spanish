# FLEX 스페인어 실전 대비 학습실

국제학교 FLEX 스페인어 시험대비 수업용 인터랙티브 학습 사이트입니다.

## 구성
| 영역 | 과 | 내용 |
|---|---|---|
| 시험 안내 | 1과 | 140문항 구성·배점·시간 배분, 영역별 공략 전략 |
| 듣기 | 3과 | Parte 1 짧은 반응 / Parte 2 대화 이해 / Parte 3 담화·강의 |
| 읽기 | 7과 | Primera~Séptima Parte (빈칸·문장의미·어휘·숙어·문법오류·비문·독해) |
| 말하기 | 1과 | 9개 과제(몸풀기·묘사·역할설정·데이터분석·의견진술) 타이머 + 모범답안 |
| 쓰기 | 1과 | 6개 유형(번역·요약·담화구성·데이터분석·서신·에세이) 모범답안 |
| 모의고사 | 1과 | 듣기 10 + 읽기 15 미니 실전 테스트 |

## 기능
- 모든 문항 **즉시 채점** + 상세 해설 + 어휘 노트
- 과별 점수 자동 저장(브라우저 localStorage) → 메인 카드에 표시
- 스페인어 문장 **원어민 발음 재생**(Web Speech API), 느리게 듣기, 음성 선택
- 대화 지문은 남녀 음성으로 번갈아 재생, 스크립트 토글

## 사용
`index.html`을 열면 됩니다. GitHub Pages 배포 시 별도 설정 없이 동작합니다.
음성 기능은 Chrome 또는 Edge에서 가장 자연스럽게 재생됩니다.

## 저작물 안내
모든 지문·문항·해설은 FLEX 시험 **유형 체계만 참고하여 새로 작성한 창작 콘텐츠**입니다.
